# F-13 — Link público do relatório

| | |
|---|---|
| **Status** | 💡 Ideia |
| **Versão** | backlog |
| **Telas** | T-11 |

## Objetivo

O cliente confere as horas do mês por um link, antes da emissão da nota, sem precisar de PDF anexado.

## Ideia

- No período fechado, gerar link assinado com validade (padrão 30 dias), revogável.
- Página somente leitura com o mesmo conteúdo do relatório ([F-09](F-09-relatorio-do-periodo.md)) e botão de baixar PDF/CSV.
- Opcional: botão "Aprovar" que registra data e IP da aprovação no período.

## A decidir

- Se a aprovação do cliente deve ser pré-requisito para emitir a nota.
